# DevSpeak Global — English from Zero to Remote .NET Jobs

Free, browser-based English practice for a developer who already knows C#, ASP.NET Core, SQL Server and ERP engineering but is starting spoken English at level zero.

## Features

- 180-day six-phase roadmap. Each day includes real beginner phrases and a separate .NET technical exercise.
- **Separate AI Engineering learning track:** 180 beginner-to-advanced days with 180 distinct easy Bangla explanations, daily C#/SQL/Python coding assignments, phase-specific setup commands, step-by-step tasks, common mistakes, 21 worked code examples and six ERP capstone checklists. Search, notes and browser-only progress are independent from English course data.
- **Exactly 5,000 authentic English words**: curated introductory/workplace vocabulary followed by a published frequency/dictionary-matched word pool. None of these words are generated by AI. Bengali definitions are sourced or editorially curated; polysemous words can have several valid meanings.
- Spaced repetition with Again / Good / Easy, search and category filters.
- Built-in speech playback with optional US, UK and Australian accents (browser voice availability varies).
- Speaking Studio using Web Speech API when available, with typed fallback and transparent keyword/word-match practice indicators. **Not a pronunciation, fluency, IELTS or CEFR score.**
- 38 .NET, SQL Server, EF Core, security, testing, Azure, ERP and architecture Q&A topics.
- Guided remote stand-up, incident, client demo, salary and technical roleplays.
- Interview and workplace writing lab, local progress, JSON export/import.
- Installable PWA with cached app assets; no backend, API key, paid inference, or login.

## Run locally

Run a static HTTP server in this folder, e.g. `npx serve .`, or `python -m http.server 8000`. Open the localhost URL. ES modules will not work correctly when the HTML is opened as a `file://` URL.

## Verify

```sh
npm run check
npm test
```

The application has no npm runtime dependencies.

## Deploy to Cloudflare Pages

1. Connect this repository to Cloudflare Pages if it is not already connected.
2. Production branch: **main**.
3. Framework preset: **None**. Build command: `exit 0` (or blank). Build output directory: `.` (the repository root containing `index.html`).
4. Allow Cloudflare's deployment to complete. The `devspeak.pages.dev` domain must be assigned to the resulting Pages project; pushing code alone does not link a new repository to that hostname.

## Data, privacy and limitations

- Read [DATA_SOURCES.md](DATA_SOURCES.md) before redistributing or monetizing the dictionary word data; the upstream sources have their own licenses.
- Progress and writing drafts are kept in browser localStorage. Export periodically. No login means no cross-device synchronization.
- Speaking transcripts are not persisted by DevSpeak, but the **browser's speech-recognition provider may process audio online**. The app does not claim offline speech recognition or scientifically valid pronunciation assessment.
- All model answers are examples. Add genuine personal project outcomes; do not invent experience, salary or performance figures in interviews.
- Some translated dictionary words have multiple meanings; the first displayed Bengali translation may not fit every context. Curated business terms receive contextual translations.
