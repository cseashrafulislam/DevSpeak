# Vocabulary sources, authenticity and permissions

The user-facing **5,000-word** module is intentionally not generated by an AI model.

## English words

The source pool for general-frequency vocabulary was filtered from the English frequency list in [first20hours/google-10000-english](https://github.com/first20hours/google-10000-english), specifically its **no-swears** edition. We retained only alphabetic tokens that also have an actual entry in the documented bilingual dictionary below, removed duplicates and then combined them with manually reviewed beginner and software-workplace words. The app takes exactly 5,000 unique entries.

The corpus is based on Google's Trillion Word Corpus, and [the upstream license note](https://github.com/first20hours/google-10000-english/blob/master/LICENSE.md) permits educational/personal/research use, but warns about commercial use without obtaining an appropriate license from LDC. **Do not repurpose the bundled ranking for a commercial vocabulary product without reviewing those terms or replacing it with suitably licensed data.**

## Bengali meanings

The general word translations come from [MinhasKamal/BengaliDictionary](https://github.com/MinhasKamal/BengaliDictionary), the `BengaliDictionary_17.txt` data. This data is published under [GNU GPL version 3](https://github.com/MinhasKamal/BengaliDictionary/blob/master/LICENSE). The repository carries source attribution and a copy of that upstream GPL text in `VOCABULARY_GPL_LICENSE.txt`.

The bilingual dictionary often lists more than one meaning for a word. This module uses one published meaning per entry, except common context-sensitive words that were manually clarified in Bengali. **A dictionary meaning is not necessarily the correct translation in every sentence.** There is no machine-generated invented word or fabricated AI translation.

## Software-workplace words and examples

An additional small set of genuine English terms and example sentences was written specifically for learning business communication and .NET interviewing, including `transaction`, `tenant`, `dependency`, `index`, `concurrency`, and `authorization`. These appear first so a beginner can practice useful terms immediately.

## Generation checks

- Every displayed English vocabulary entry contains alphabetic English letters only.
- Every displayed entry has a non-empty Bengali meaning.
- There are exactly 5,000 entries with no duplicate English word after case-normalization.
- Unit tests verify these invariants at each code change.
